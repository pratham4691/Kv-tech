# Kv-tech Project Instructions & Context (Claude Code)

## Mission: The "Phoenicx" Autonomous Cryptographic Rebirth Experience
You are working on **Kv-tech (Kalki Vault)**, an enterprise-grade cybersecurity and cryptographic vault ecosystem built with **Next.js 16.3**, **React 19**, **Tailwind CSS v4**, and **Framer Motion 13**.

### Brand & Architectural Identity:
- **Project Name**: Kalki Vault // Kv-tech
- **Signature Experience**: **"Phoenicx"** (Scroll-driven autonomous resilience & rebirth engine)
- **Aesthetic**: Deep obsidian cybersecurity dark mode (`#010309`, `#02040a`), cyan lasers (`#06b6d4`, `#22d3ee`), ultraviolet accents (`#a855f7`), emerald security seals (`#10b981`), frosted glassmorphic HUD telemetry.

### Core Architecture & Recent Changes:
1. **Lenis Inertia Scrolling**: Configured in `components/smooth-scroll-provider.tsx` and injected into `app/layout.tsx`.
2. **Phoenicx Scroll Sequence**: Built in `components/phoenicx-scroll.tsx`, linked to 380vh scroll track with 4 sequential transformation stages:
   - **Stage 1 (0% - 25%)**: Heuristic zero-day breach, cracked polygonal vault core, glowing floating ember particles (`MEM_FAULT: 0x7FFF9A`).
   - **Stage 2 (25% - 55%)**: 3D vault deconstruction and plasma core ignition. Geometric cyber-wings unfold via parametric SVG paths.
   - **Stage 3 (55% - 78%)**: Full wingspan expansion across viewport with expanding radial blastwaves and status flipping to "100% PURIFIED".
   - **Stage 4 (78% - 100%)**: Wings lock into sovereign crest, staggered interactive resilience doctrine cards glide in with hover highlights.
3. **Interactive Features**: Real-time "TEST INTRUSION" simulation button on the HUD.
4. **Main Landing Page**: Orchestrated in `components/landing-page.tsx`.

### Directives for Claude Code:
- Prioritize high visual fidelity, micro-interactions, and cinematic motion.
- When adding or refining components, maintain the strict dark cybersecurity aesthetic.
- Preserve existing Tailwind v4 theme definitions in `app/globals.css`.
